# Rut IQ Product Direction — Current Sightings First

Rut IQ is a live hunter-reported rut activity network. Current, real hunter observations are the core product and must drive the map, Home summaries, trends, and notifications.

- Never use historical breeding dates to color the live map, imply current activity, or fill gaps in reports.
- No historical rut layer is planned for launch. The historical-rut-data-plan.md file is archived research, not an implementation mandate.
- Gray/empty areas mean no reports or insufficient evidence, never no deer activity.
- Show report recency, number of reports, independent contributing hunters, and activity types when privacy-safe.
- Test Mode reports must remain isolated and clearly labeled.
- Avoid precise hunter locations or identifying contributors; aggregate at county level.
- Avoid overstating conclusions from sparse, self-reported, or unverified observations.
- Free experience should make live reporting and viewing useful; Pro adds deeper current-activity analysis rather than hiding basic reports.

Priority: reliable current sightings -> useful county/nearby summaries -> transparent trends -> mobile usability -> subscriptions -> Shopify launch.
